# LLM 분석 정책

## 현재 공급자

- 공급자: Google Gemini Developer API
- 기본 모델: `gemini-3.1-flash-lite`
- 프롬프트 버전: `trend-analysis-v1`
- 인증: 서버 환경변수 `GEMINI_API_KEY`

`gemini-2.5-flash-lite`는 가격 문서에 무료 등급이 남아 있지만 신규 사용자 요청에서는 사용 종료 응답을 반환하므로 사용하지 않는다. 현재 신규 키에서 동작하며 공식 무료 등급이 명시된 `gemini-3.1-flash-lite`를 기본값으로 선택했다.

## 안전 원칙

- 키는 `NEXT_PUBLIC_` 환경변수로 만들지 않으며 브라우저 번들에 포함하지 않는다.
- 점수와 순위는 LLM이 계산하지 않는다.
- 수집 출처와 공식 확인 사실만 프롬프트에 제공한다.
- 구조화 출력은 Gemini JSON Schema와 애플리케이션 Zod 스키마로 두 번 검증한다.
- 스키마 검증에 실패한 출력은 저장하지 않는다.
- 결과에는 공급자, 모델, 프롬프트 버전, 생성 시각, 토큰 사용량을 함께 기록한다.
- `429`와 `5xx`만 재시도 가능한 오류로 분류한다.

## 무료 등급 주의사항

- 결제 계정은 연결하지 않는다.
- 무료 등급에는 호출량 제한이 있으며, 제한 도달 시 분석을 임의 데이터로 채우지 않고 `분석 대기 중` 또는 `LLM 분석 실패` 상태로 처리한다.
- 무료 등급에 제출된 콘텐츠는 Google 제품 개선에 사용될 수 있으므로 개인정보·비공개 데이터·사용자 메모는 전송하지 않는다.
- Google Search grounding은 초기 분석 경로에서 사용하지 않는다.

## 다음 연결 지점

`@ai-trend-radar/llm`의 `TrendAnalysisProvider`를 worker의 일일 후보 분석 작업에서 호출한다. 공개 웹 요청에서 직접 호출하면 무료 쿼터가 소진될 수 있으므로, 관리자 재생성 API는 인증·권한 검사와 호출 제한을 구현한 뒤 연결한다.
