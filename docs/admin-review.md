# 관리자 후보 검토

## 권한

- 웹 관리자 역할은 Supabase Auth의 서버 전용 `app_metadata.role=admin`을 기준으로 검증한다.
- 관리자 조회·수정은 서버 액션에서만 secret key를 사용한다. 브라우저로 secret key를 전달하지 않는다.
- 일반 사용자가 `app_metadata`를 직접 수정할 수 없다.

## 검토 흐름

1. `/admin/review`에서 `review` 후보를 조회한다.
2. AI 분석 완료 후보를 점수순으로 우선 표시한다.
3. 서비스명·도메인·카테고리 검색과 분석 완료 필터를 제공한다.
4. `승인·공개`는 `visibility=public`, `보류`는 `visibility=private`로 변경한다.
5. 공개된 엔티티만 메인·탐색·상세·사이트맵에 노출된다.
